HOW TO PUBLISH
1. Open your repo: Yousuf-Hozaifa.github.io
2. Upload ALL of these files and the "assets" folder to the ROOT of the repo
   (replace the old index.html). Commit.
3. Wait 1-2 minutes. Your link stays: https://yousuf-hozaifa.github.io

WHAT EACH FILE DOES
index.html          page structure (you rarely edit this)
robots.txt          tells Google it can read the site
sitemap.xml         lists your page for Google
assets/content.js   ALL YOUR TEXT AND LINKS. Edit this file to add projects,
                    start dates, live demo links, research, skills.
assets/style.css    colors, fonts, layout
assets/app.js       builds the page from content.js
assets/portrait.png your photo (replace with a real photo, same file name)
assets/resume.pdf   file behind the Download CV button
