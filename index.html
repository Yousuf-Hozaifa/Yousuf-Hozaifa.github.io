Research

My lab work sits where machine learning meets privacy, security, and interpretability.

Fed-MU: modality-preserving federated unlearning for medical AI

Submitted to ICCIT 2026 · AMIR Lab

Studies how patient-specific information concentrates in the cross-modal adapter of LLaVA-1.5-7B, and how to remove it in a federated setting without retraining and without breaking image–text alignment. Built and validated on IU X-Ray.

Code on GitHub

Tool Use Across Scale: do large-model tool-calling strategies transfer to small models?

Submitted to ICCIT 2026

An evaluation framework for 1B–3B parameter models on the API-Bank benchmark, comparing retrieval-based tool filtering, schema simplification, and sequential tool search. On Llama-3.2 and Qwen2.5, retrieval filtering mainly improves token efficiency and tool-calling reliability, not raw tool-selection accuracy.

LEAD: latent-entropic adversarial defense for LLMs

Active research · manuscript in preparation

A two-stage defense against gradient-based attacks (GCG) and fluent jailbreaks (PAIR, AutoDAN). A DistilGPT2 entropy screen runs on a single T4 GPU, and latent-space analysis of Llama-3-8B finds a consistent refusal direction.

  • Preliminary: all gradient-based attacks detected (GCG, N > 350)
  • Preliminary: 97.1% robustness to fluent jailbreaks (PAIR, AutoDAN)
  • Preliminary: 98.86% pass rate on benign instructions

The Adversarial Circuit: how prompt injection steers an agentic RAG system

Active research

A mechanistic interpretability study of how prompt injections steer Llama-3-8B-Instruct inside agentic RAG systems. It tracks hidden-state trajectories across layers using PCA, UMAP, Tuned Lens and Logit Lens. It informs the injection filter in my gateway project.
